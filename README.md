Skyline Courier — a chase-view flight game over a seeded valley: fly through glowing target rings, manage fuel and wind, and land on the runway. Three missions (Ring Run, Precision Landing, Slalom Sprint) with escalating difficulty, a full HUD (speed, altitude, heading, fuel, compass, artificial horizon), keyboard + mouse/touch controls, and deterministic seeded terrain so every run is fair.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — pick a mission (keys 1–3), press Space to fly. Steer with arrow keys / WASD (pitch and bank), Shift/Ctrl for throttle, or drag on the canvas. Fly through rings to score and refuel; in Precision Landing, line up on runway 09 and touch down gently.
